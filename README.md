# La Mecánica de Motos – Andahuaylas

Sitio web para **La Mecánica de Motos**, taller especializado en motos Bajaj y TVS en Andahuaylas, Apurímac, Perú.

## Secciones

- **Inicio** — Hero con animaciones, partículas y estadísticas.
- **Servicios** — 9 servicios con precios de referencia.
- **Repuestos** — Catálogo de productos con filtros por categoría.
- **Galería** — Galería de trabajos con filtros y lightbox.
- **Proceso** — Timeline del proceso de atención.
- **Nosotros** — Razones para elegirnos.
- **Testimonios** — Reseñas de clientes.
- **Marcas** — Bajaj, TVS, Honda, Yamaha.
- **Contacto** — Formulario → WhatsApp + datos de contacto + mapa.

## Características

- Diseño oscuro, industrial y deportivo
- Fondo negro con acentos en rojo (#E8001D) y dorado (#F5A623)
- Tipografías condensadas en mayúsculas (Bebas Neue, Barlow Condensed)
- Menú fijo semitransparente con desenfoque
- Hero a pantalla completa con partículas animadas y cuadrícula
- Contadores animados
- Filtros interactivos para galería y productos
- Lightbox para galería
- Botón flotante de WhatsApp
- Formulario que envía a WhatsApp
- SEO optimizado con meta tags
- 100% responsive (mobile-first)
- Sin dependencias externas — HTML/CSS/JS puro

## Despliegue

Sitio estático — simplemente despliega en Vercel, Netlify o cualquier hosting estático.
