# La Mecánica de Motos — Andahuaylas

Sitio web para **La Mecánica de Motos**, taller especializado en motos Bajaj y TVS en Andahuaylas, Apurímac, Perú.

## Tech Stack

- **React 18** + **Vite 5**
- **Tailwind CSS 3**
- **React Router DOM 6**
- **ESLint** con plugins de React

## Páginas

- `/` — Inicio (hero, servicios, proceso, testimonios, marcas)
- `/servicios` — Todos los servicios con precios
- `/repuestos` — Catálogo de productos con filtros
- `/galeria` — Galería de trabajos con filtros y lightbox
- `/contacto` — Formulario → WhatsApp + datos + mapa

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
